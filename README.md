## ⚡ Features
- **JWT Authentication**: Secure login for Users and Admins
- **User Login & Admin Login**: Role-based access control
- **Score Management**: Enter and update last 5 Stableford scores
- **Draw System**: Monthly draws with multiple match types (3, 4, 5-number matches)
- **Subscription Plans**: Monthly & Yearly, with Stripe integration
- **Charity Selection**: Choose charity and set contribution percentage
- **Winner Verification**: Admin approves score submissions and manages payouts
- **Dashboard**: View subscription status, scores, charity contributions, and winnings

---

## 🛠️ Tech Stack
- Frontend: React / Next.js
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT ,bcrpt
